# 🏋️ Sport Academia

Site institucional para academia de musculação em Campo Limpo Paulista, SP.
Desenvolvido com HTML, CSS e JavaScript puro — sem frameworks.

---

## 🖥️ Tecnologias

- HTML5 semântico
- CSS3 Mobile First (tema claro/escuro)
- JavaScript ES6+ puro
- Font Awesome 6.7.2 (CDN)
- Google Fonts — Oswald + Poppins

---

## 📑 Seções

- Hero
- Sobre
- Serviços (6 modalidades)
- Equipe (4 profissionais)
- Galeria (lightbox)
- Depoimentos (carrossel)
- Agendamento (envio via WhatsApp)
- Contato (Google Maps)
- Footer

---

## 🚀 Como rodar

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/sport-academia.git

# Abra no navegador
open index.html
```

Ou use a extensão **Live Server** no VS Code.
